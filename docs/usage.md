# 使用指南

[返回 README](../README.md) · [验证状态](validation.md)

## 连接与设备选择

手机需要解锁并选择 USB“文件传输”，无需开启 USB 调试。单台手机接入时自动连接；多台接入时，在左侧“我的设备”选择其中一台，再点击“手动连接”。同名手机可按 USB 位置区分。

应用始终只有一个活动会话，仅打开所选手机。拔掉其他手机不影响当前连接；拔掉所选手机后清空浏览，其他已接入手机需手动连接。切换手机先释放旧会话并清空目录和媒体缓存。

连接失败会有限重试，随后保留手动连接入口。手动连接或停止会取消该次后台重试；主动断开后不会立即自动接管回来。演示模式不监听真实 USB。

“设置 → USB 连接”允许临时接管被系统相机服务占用的手机。本地包通过 macOS 管理员认证启动一次性 helper，连接成功后永久降回发起用户权限，才处理浏览、预览与下载。不会安装后台服务、保存密码或终止系统相机服务。接管可能短暂影响所选手机的照片导入或 ADB；拒绝授权后可手动重试。关闭此设置仍可尝试普通连接。技术细节见 [USB 授权说明](usb-access.md)。

## 浏览、排序与缓存

单击文件名或左侧复选框选择项目，支持 ⌘ 追加、Shift 范围选择和“全选”。双击目录或点击目录箭头进入。列表与预览网格共用选择。

点击路径中的祖先可直接返回，存储名称返回根目录；路径较长时通过省略号菜单选择。当前路径和最近访问的目录优先使用缓存；手机上新增或修改内容后，请点击“刷新目录”。换存储、断开、重新连接或切换模式会清空缓存。

默认按名称自然升序排列，例如“照片2”排在“照片10”前面。点击名称、大小、类型、修改日期列标题改变排序，再次点击切换升降序；始终文件夹置顶。排序保留仍可见的选择，返回缓存目录时沿用当前排序。

受支持的非根目录使用快速浏览，优先显示名称、类型与修改日期，文件大小显示“未读取”。点击“读取大小”或首次按大小排序，会为当前目录补齐大小并保留筛选与选择。根目录和不支持批量属性的设备可能直接读取完整大小。

下载和完整预览会重新核实真实大小，不依赖浏览中的“未读取”值。快速浏览不能省掉手机端首次目录枚举，首次打开大目录仍可能等待较长时间。

### 经常访问

连接手机后，左侧“经常访问”会列出最多 8 个成功打开过的目录，按访问次数排序，次数相同时优先显示最近访问的目录。根目录和手动刷新不增加访问次数；失败或取消的打开不计入。每条记录显示目录名、存储及父路径，悬停可查看完整路径。

点击即可跳转，不需要逐层双击。已有目录快照时直接恢复；重连后按目录名称路径重新查找，不复用上次连接的对象 ID。首次定位深层目录可能需要读取各级父目录，目录已移动、改名或删除时会提示，并保留原来的浏览位置。下载期间可使用入口，手机读取安排在当前完整文件之后。

记录按手机和存储隔离，只保存在本机，最多保留最近使用的 200 条。能验证 USB 序列号的手机可跨重连/重启保留；无法可靠区分设备时只保留本次连接记录，演示模式单独记录。隐藏路径遵循“显示隐藏文件和文件夹”设置。右键“从经常访问中移除”只删除本地历史，不会删除手机目录；之后再次访问可以重新加入。

## 筛选与隐藏文件

搜索、年月、类型和隐藏设置共同决定当前可见列表。被筛选隐藏的项目会取消选择，“全选”和下载仅使用当前可见的所选对象。

### 按年份、月份或媒体类型下载

1. 进入 `DCIM/Camera` 等目录，等待加载完成。
2. 选择“修改年份”“月份”或图片/视频类型，可叠加文件名搜索。
3. 点击“全选”，再点击“下载到 Mac”或“加入下载队列”。

年月按手机返回的**修改日期**和 Mac 本地时区归类，不读取 EXIF 拍摄日期。“全部年份”下可跨年筛选同一个月份。缺少有效日期的文件归入“日期未知”。年份数量按类型和隐藏条件统计，月份数量额外受当前年份影响；搜索后的匹配数量看列表底部。

手机返回的日期没有时区时，按 Mac 本地时间解释，建议手机与 Mac 使用相同时区；带明确时区的日期会转换为 Mac 本地时间。文件名中的日期可能是拍摄日期，与实际修改日期不一定相同，筛选以“修改日期”列为准。

具体年份、具体月份、“日期未知”以及图片/视频筛选均排除文件夹；具体月份也排除日期未知的文件。要进入子目录或递归下载整个文件夹，请恢复全部条件或点击“清除筛选”。

刷新保留年月与类型条件，即使没有结果也不会自动放宽。跨目录、换存储或重新连接时恢复全部年份、月份与类型。筛选期间暂时禁用选择、预览和下载，完成后按新结果恢复。

图片/视频按扩展名分类，不区分大小写。图片包含 JPG、PNG、HEIC、WebP、GIF、TIFF 及常见 RAW 等；视频包含 MP4、MOV、MKV、AVI、WebM 等。完整扩展名表见 [Models.swift](../Sources/FerryCore/Models.swift)。分类支持不代表 macOS 能解码所有格式，未识别文件仍可在“全部类型”中选择下载。

### 隐藏文件

在“设置 → 文件显示”开启“显示隐藏文件和文件夹”，默认关闭，重启后保留。关闭时，下载整个文件夹也会递归跳过点号文件和隐藏目录；开启时全部包含。

搜索和年月/媒体筛选只决定当前列表可选择的对象，不会继续筛选所选文件夹内部的普通文件。递归下载范围受隐藏设置影响。

## 下载队列与报告

选择 Mac 保存位置后，点击“下载到 Mac”。下载期间可继续在已加载目录选择项目，点击“加入下载队列”；成功入队会出现确认提示，可跳转到“下载任务”页面。

默认记住上次确认的保存位置，无需开启设置。首次使用为系统“下载”目录，之后重启会恢复上次选择；取消文件夹选择不改变记录。鼠标停在保存位置名称上可查看完整路径。目录不可用或无法写入（例如外接硬盘未连接）时，点击下载会提示连接硬盘或重新选择，不会自动切换目录、创建缺失目录或启动该下载。原目录恢复后可再次点击下载；目录被移动、重命名或硬盘挂载路径变化时，可通过“更改…”重新选择。

每条任务固定入队时的手机、存储、对象、保存位置和隐藏设置。之后更改筛选或保存位置不会修改已入队任务。始终只有一个任务传输，下一条在当前任务结束后自动执行。

左侧“下载任务”入口显示未结束任务数量。任务页提供进度、已用时长、预计剩余、取消、继续队列、清理已结束任务和结果目录。切页保留浏览路径、筛选、选择和列表状态，队列持续执行。

任务列表中最新添加的任务显示在最上面，下载仍按入队顺序依次执行。完成、失败、取消或继续任务时保持原列表位置。

每条任务标题下显示添加任务时的筛选条件，包括类型、修改年份、修改月份、搜索词和是否包含隐藏文件，方便区分不同批次；没有限定的类型、年份或月份会明确显示“全部”。长摘要最多显示两行，鼠标悬停可查看完整内容。之后修改浏览筛选或继续已取消任务，原任务的摘要保持不变。摘要用于回看当时的浏览条件；实际下载仍以当时选择的项目为准，搜索词只筛选当前目录。

每条任务使用独立边框卡片，顶部显示名称与状态，进度下方按四列展示文件数量、传输量、用时及速度/预计剩余。文件名与“取消任务”“继续未完成”“查看报告”“打开文件夹”等操作位于卡片底部；长文件名可悬停查看完整内容。

任务完成、取消或失败后，有有效传输量和用时的任务会显示平均速度（自动使用 B/s、KB/s、MB/s 等单位）。平均速度为已传输字节除以任务总用时，包含准备、等待选择和收尾时间，不包含入队后尚未开始的排队时间；结束后数值固定。传输量包含已从手机读取但随后跳过的文件，exFAT 提交时的本地复制不重复计数，因此该数值不代表目标磁盘的净写入速度。

使用“继续未完成”后，从本次继续开始重新计时。进度会随核验重新统计；平均速度只计算本次新传输的字节，不把已核验复用的旧文件计为新下载。核验时间计入本次用时，全部内容都可复用而没有新传输时不显示平均速度。

任务卡片的进度条上有小舟，随实际进度向右移动。下载时小舟会轻微浮动、摇摆；总量尚未确定时停在起点浮动。切页、滚出视口、应用进入后台、窗口最小化或完全遮挡后暂停动画；等待选择或正在停止时，小舟保持静止。任务完成时，小舟靠岸后淡出，进度条右端点保留小码头和小旗；取消时，小舟停在原位置并放下灰色船锚；失败时，原位置显示带感叹号的橙色浮标。进度条和状态标记保留。实时完成时，小舟先到达终点并淡出，码头渐入、小旗升起，整个交接平滑衔接，随后保持静止；查看历史任务或切回页面时直接显示静态结果。系统开启“减少动态效果”时跳过浮动、进度插值和靠岸动画，进度仍正常更新。

已有缓存目录可即时浏览；新目录读取需等待当前完整文件结束，再继续下载。等待目录时停止浏览不取消当前文件。下载期间暂停新的缩略图读取和完整预览。

### 取消、失败与退出

- 等待任务可单独取消。取消活动下载会先等待当前文件或设备操作结束，再发送任务取消请求；当前文件可能完成并保留，剩余文件不再开始。等待同名冲突选择时取消则直接结束等待，并清理已存在的临时文件。健康的 helper 会话继续保留，新任务可复用，通常无需再次管理员授权。大文件或目录规划可能需要较长等待。
- 已取消、断线或失败且有恢复记录的任务提供“继续未完成”。正常退出、重新打开应用或拔插手机后也可继续；重新打开时未完成任务显示“等待恢复”，不会自动传输。先连接原手机及存储、确认原保存位置可用，再点击继续。新的任务会自动保存恢复记录，无需开启设置；旧版本留下的报告不会自动导入。
- 恢复沿用原保存目录、实际编号/归档路径、下载设置、筛选摘要和报告，不另建批次目录。重连后重新查找原手机目录和文件；需要恢复的源文件名称、大小或修改日期变化、文件缺失或名称有歧义时停止并说明原因。已完成文件核对本地长度和 SHA-256，匹配后跳过手机内容读取，缺失或损坏时重新下载并遵守同名冲突规则。明确跳过的项目保持跳过，未完成的单个文件从头读取，“全部应用”策略重新选择。
- 核验按单个文件分步执行，数量多或文件大时需要等待，也可以在文件边界再次取消并继续。其他任务正在运行时，恢复任务进入队列，不中断当前文件。原保存位置不可用时保留记录，可连接原硬盘后重试；当前“更改…”不修改旧任务的原目标。手机没有提供稳定标识时，会说明本任务仅能在当前连接内继续。
- 若取消等待期间发生真实 USB/协议错误，当前任务报告错误，后续队列暂停，避免自动反复重新连接和授权。若最后一个文件已经完成，任务按完成处理。重新连接原手机后，可手动继续有恢复记录的任务或继续队列。
- “清理已结束”只移除无需继续的结束任务，可恢复的任务会保留。卡片上的“移除任务”删除该任务的恢复入口，不删除已下载内容或报告。已完成任务的历史列表仅保留在当前运行中，未完成任务的恢复记录会保存到下次启动。
- 退出或关闭主窗口前仍会确认，默认取消；确认后停止传输并清理会话，保存未完成任务供下次手动继续。正常退出不保留半文件；强退或拔盘可能留下临时文件或尚未完整提交的文件，恢复时遵守同名检查，不自动覆盖。

### 保存结构与校验

默认把所选文件或文件夹直接保存到指定位置，所选文件夹的内部层级保持不变。同名文件会弹窗显示完整目标路径、两份文件的大小和修改日期，可选择“保留两者”“跳过”“替换”或“停止任务”。“保留两者”为默认按钮，会添加 ` (1)`、` (2)` 等编号；“跳过”保留原文件；“替换”仅在新文件已完整下载、同步并校验后，以原子重命名替换本地普通文件，不先删除或截断旧文件。文件夹、符号链接等非普通文件不能替换。普通源文件夹仍另起编号目录，不与已有目录合并。勾选“为本次下载创建文件夹”后，把该任务内容保存到新建的 `渡舟-日期时间-随机标识` 目录；此偏好会保存，入队后修改不会影响已有任务。

“应用到本次任务的所有同名文件”只影响当前任务，新任务会重新询问；它不作用于月份目录的选择。不同月份的多目录选择分别确认。同名不等于内容相同，跳过不是内容去重。

普通文件在读取手机内容前检查同名冲突；选择“跳过”直接保留原文件，省去该文件的传输和临时写入。“应用到本次任务的所有同名文件”也会提前跳过后续同名文件，无冲突文件继续正常下载。按拍摄年月归档的图片和视频首次仍需完整下载到隐藏临时目录，读取日期后才能确定目标月份；恢复任务中已确定的路径可提前检查。下载期间新出现的同名文件也会在保存前询问。

等待选择期间暂停下载，不重复读取手机；在弹窗中停止会清理已有临时文件，断线或退出也走正常清理流程，保留原文件和已完成文件。原文件在等待或下载期间发生变化时，单独确认的替换会重新询问。报告通过 conflictAction 标记 keepBoth / skip / replace，跳过项目的 state 为 skipped，任务页单独显示跳过数量；提前跳过的文件没有内容哈希，读取后跳过的哈希属于新文件，不是对原文件的校验。进度包含提前跳过的文件大小，传输速度和预计剩余时间不把这些字节算作实际读取。

传输报告通过“下载任务 → 查看报告”在应用内查看，不写进用户的照片或目标目录。本地存放位置为：

```text
~/Library/Application Support/Ferry/Transfers/transfer-随机标识/
├── 传输报告.json         初始计划、实际保存名称与最终结果
└── 任务记录.ndjson       逐文件状态记录
```

下载前与写入期间检查空间，预留 64 MiB；临时文件经过长度检查后提交，默认不覆盖已有文件，仅在明确选择“替换”后更新对应本地普通文件。APFS 等支持独占重命名的卷采用原子提交；exFAT 等不支持该操作的卷先完整下载并校验，再以仅新建方式复制到最终文件，同时核对长度和 SHA-256。该兼容路径会多一次本地复制，空间预检额外预留最大单文件大小；复制过程中最终文件可能短暂不完整，正常取消或失败会清理未完成文件。强退或拔盘可能留下未完成文件，应结合任务报告核对。保留目录结构和空目录；设备提供有效修改时间时，为下载文件保留该时间，目录本身的修改时间不恢复。SHA-256 在本地写入时计算，不表示已与手机端摘要比对。

### 按拍摄年月归档图片

在“设置 → 下载”开启“按拍摄年月归档图片”，默认关闭并记住选择；任务使用入队时的设置。开启后，图片按 `2026/01月/照片.jpg` 这样的路径保存到所选位置；勾选“为本次下载创建文件夹”时，则保存在该批次文件夹下。

新月份目录默认使用 `01月` 等格式；已有 `01月`、`1月`、`01`、`1` 等名称时，唯一的真实目录会自动复用。多个匹配目录同时存在时，先选择本次任务要使用的目录，该月份后续图片沿用此选择；不合并或迁移其他目录。同名照片再按文件弹窗选择处理。若年月路径被普通文件或符号链接占用，任务提示路径冲突并保留原项目，不替换它。新建的结构性目录名固定使用四位年份、两位月份加“月”，无日期目录固定为“日期未知”，不随界面语言改变；复用的旧月份目录保留原名称。

日期优先使用 EXIF 的“原始日期时间”；缺失或无效时使用手机修改日期，再缺失则进入“日期未知”。有 EXIF 时区时按拍摄当地的年月归档，未记录时区时使用 Mac 本地时区；修改日期回退也使用 Mac 本地时区。列表年月筛选仍依据修改日期，因此筛选年份与最终拍摄年份可能不同。不会用导出时新建文件的创建日期猜测月份。

只对新导出的图片进行归档，不移动已有文件。所选文件夹中的图片统一归入输出根目录下的年月目录；未开启归档的类型保留原目录结构，实际空目录也会保留，不生成仅包含已归档媒体的空相册目录。传输报告的 sourcePath 记录图片原路径，path 记录实际保存路径，archiveDateSource 标明 exif / modified / unknown，archiveDate 记录选用的日期。

此选项与“将照片创建日期设为拍摄时间”独立：可以只归档而不改创建日期。两者同时开启时共用一次本地 EXIF 读取，不重复读取手机，也不重写图片。

### 按拍摄年月归档视频

在“设置 → 下载”开启“按拍摄年月归档视频”，默认关闭、记住选择，并在任务入队时冻结。它与图片归档独立；两者都开启时共用相同的年份/月目录及旧月份目录选择，同名视频沿用保留两者、跳过或替换的规则。只处理本次导出的内容，不移动已有文件；取消后继续也保留原归档设置和已保存路径。

MP4、MOV、M4V、3GP/3G2 等 ISO BMFF/QuickTime 容器优先读取有效的内嵌日期，其次读取容器创建时间；没有有效日期时使用手机修改日期，再缺失放入“日期未知”。其他已识别的视频格式直接使用手机修改日期。不会从文件名或本次导出产生的文件创建日期猜测拍摄月份，1904 等初始化占位日期也不会用于归档。

内嵌日期带时区时保留其记录的年月，无时区时使用 Mac 本地时区；容器头中的 UTC 时间戳转换成 Mac 本地年月，无法凭 UTC 时间戳还原未知的拍摄地时区。剪辑、转码或转发可能重写这些日期，它们不保证等于原始拍摄时间。传输报告使用 video_metadata / container / modified / unknown 标明来源，并通过 archiveDateWarning 记录损坏或超限元数据的读取问题；读取失败会回退日期，不中止正常下载。列表年月筛选仍使用手机修改日期。

视频日期只从已下载的本地文件读取，不解码、不转码、不额外读取手机内容。解析器跳过视频内容块，只读取有上限的元数据；元数据位于文件尾部时会产生本地随机读取，实际额外耗时取决于文件和目标盘。视频的文件内容、修改日期和创建日期不因归档选项而改变；“将照片创建日期设为拍摄时间”仍仅作用于图片。真实手机和外接盘的大批量视频归档耗时尚待实测。

### 照片创建日期

“设置 → 下载”提供“将照片创建日期设为拍摄时间”，默认关闭并记住选择；每条任务使用入队时的设置。开启后，仅对本次新下载的图片，从本地文件读取 EXIF 的“原始日期时间”（DateTimeOriginal），设置 Finder 显示的文件创建日期，保留手机修改日期和原始图片内容。不会修改 EXIF、重写图片、额外读取手机或处理之前已经导出的文件，也不影响年月筛选。

有 OffsetTimeOriginal 时尊重其时区；没有时区时按 Mac 本地时区解释。缺失或无效的日期保持现状，不从文件名、修改时间或其他 EXIF 日期猜测。文件系统精度可能影响小数秒；创建日期设置失败不影响已下载内容，原因记录在传输报告的 creationDateWarning，成功应用的时间记录在 photoCreationTime。

本选项和年月归档都关闭时不会解析 EXIF。开启任一项时使用系统 ImageIO 读取必要的本地元数据，不解码像素或重新编码；实际额外耗时取决于文件格式、数量与目标盘，尚无真实手机批量备份的量化对比。

正常完成、取消或失败后，报告更新为最终状态。进程崩溃或强制退出可能留下未完成文件，报告也可能仍显示运行中；逐文件记录可辅助核对，有恢复记录的任务可手动继续，未完成的单个文件从头读取。报告包含文件名和设备显示名称，应按个人文件保管。

## 本地工具

侧栏打开“本地工具”后，首页以两列卡片展示图片/视频日期修复、重复图片整理、图片/视频归档和按拍摄时间重命名。每张卡片都有用途说明；点击卡片进入独立操作页面，顶部“返回本地工具”可回到首页。

扫描或处理时可以返回首页，卡片会显示正在扫描、修复、清理或归档；点击运行中的卡片可回到进度页。为避免同时处理同一批文件，其他工具暂时显示等待并不可打开。已扫描或处理完成的工具会显示查看结果入口，有错误时提示查看详情；返回首页和切换侧栏页面保留计划、选项和结果，不打断任务。重新启动应用后需要重新选择文件夹和扫描。

## 本地图片/视频日期修复

侧栏打开“本地工具”，点击“图片/视频日期修复”卡片，可将硬盘上已有图片和视频的创建日期恢复为拍摄时间，无需手机连接。

1. 点击“选择文件夹…”。图片、视频和包含子文件夹默认开启，可分别取消。修改类型或其他选项后重新扫描。
2. 等待扫描，查看待修复数量和前 20 个文件的当前创建日期、目标日期及来源。扫描不会修改文件日期。
3. 图片优先 EXIF 拍摄时间，视频优先系统能读取的内嵌拍摄/创建时间或容器日期；没有有效元数据时，从文件名识别日期。可关闭文件名补充，或关闭“仅恢复年月日”。
4. 默认只修复创建日期，修改日期保持原样。如需两者一致，勾选“同时修复修改日期”并重新扫描，预览会另显示修改日期的变化。
5. 核对预览后点击“修复 N 个文件”，按已选模式批量调整日期。页面会显示进度、成功/跳过/失败数量及最多 50 条问题详情。

| 文件名示例 | 没有有效 EXIF 时的推测结果 |
| --- | --- |
| `20130607_190722.jpg` | 2013-06-07 19:07:22 |
| `20121209_015.jpg` | 仅能确定 2012-12-09；允许“仅恢复年月日”时设为 00:00，015 不作为时间 |

文件名日期可能来自导出或重命名，请核对来源后再修复。无可靠日期、日历日期无效或含多个冲突日期的文件跳过。EXIF 明确的时区偏移会被采用，无时区及文件名日期按 Mac 当前时区解释。

视频文件名如 `VID_20250704_005959.mp4` 也可在缺少有效元数据时识别为 2025-07-04 00:59:59，来源会在预览中标明。其他格式是否支持视频内嵌时间取决于系统；读取不到且文件名不可识别时跳过，不从文件当前日期推测。

工具保留原文件名、图片和视频内容及内嵌元数据，不转换格式。默认保留修改日期；勾选同步修改时，创建和修改日期设为同一目标日期，不重编码、不删除或重命名文件。隐藏文件（如 ._ 侧车文件）、链接、照片资料库和应用包不处理；扫描后发生变化的文件也会跳过。部分磁盘时间精度有限，可能按秒取整。停止或退出仅停止剩余操作，已修复的日期保留；再次扫描会跳过日期已一致的文件。切换页面不打断工作，本地修复不受手机演示模式影响，处理的是你实际选择的本机文件夹。

## 重复图片整理

在“本地工具”首页点击“重复图片整理”卡片，无需手机连接。

1. 选择文件夹，等待扫描；默认包含子文件夹。工具先比较大小，再计算完整文件 SHA-256，扫描不会修改图片。
2. 每组展开可查看完整路径和日期，选择要保留的一份。也可使用“优先保留指定文件夹…”批量设置，日期仅供参考。
3. 勾选要清理的组，或点击“全选重复组”。默认不勾选任何组，界面会显示将移动的副本数量及总大小。
4. 点击“将 N 份副本移到废纸篓”，确认后执行；每组保留选定的一份，其余副本移入系统废纸篓。

只有完整字节相同的图片算重复；文件名和日期可以不同，视觉相似但压缩/EXIF 不同的照片不会被自动分组。隐藏文件、链接、空图片文件和资料库不处理。保留项或副本在扫描后变化会被跳过，保留项缺失时不会继续清理该组；废纸篓不可用会报告失败，不直接永久删除。

停止或退出只停止剩余工作，已移动的文件可在 Finder 废纸篓中找回；处理后请重新扫描。工具不会自动清空废纸篓，显示的副本大小不代表立即释放的磁盘空间。本地工具的扫描计划及结果仅保留在本次运行，切页不会丢失，重新打开应用需要重新扫描。

## 本地图片/视频年月归档

已导出但尚未按年月整理的文件，可在“本地工具”首页点击“图片/视频归档”卡片批量整理，无需手机连接。

1. 选择待整理文件夹。默认处理图片和视频并包含子文件夹，可分别关闭；修改选项后重新扫描。
2. 查看来源和目标路径预览。每页 20 个，可通过预览顶部或底部的“上一页／下一页”查看全部结果，并核对总数、当前范围和页码。翻页后自动回到预览顶部；重扫、更换文件夹或修改选项后从第一页开始。每个文件前可逐项勾选，默认选择待归档文件；已在目标目录的文件标记无需处理且不可勾选。支持“本页全选”以及“全部选择／清空选择”，跨页保留勾选。归档只处理勾选项，不受当前预览页影响。图片优先 EXIF 拍摄时间，视频优先系统能识别的内嵌拍摄/容器创建元数据；没有有效元数据时先识别文件名日期，再用文件创建日期，均不可用时进入“日期未知”。本地归档不使用修改日期，下载设置的归档规则不变。
3. 文件整理到所选文件夹内的 `2022/02月/` 等目录。已有 `02月`、`2月`、`02`、`2` 时复用；同月有多个候选目录时，先选择归入哪一个。
4. 核对已选择数量，点击“归档已选 N 个文件”并确认。未勾选的文件保留原位；未选文件对应的月份无需先选择归档目录。文件会从原路径移动到年月目录，已经位于目标目录中的文件保留原位；同名时弹出与下载备份相同的处理窗口，展示两份文件的路径、大小和修改日期，选择“保留两者”“跳过”“替换”或“停止归档”。“保留两者”默认追加 ` (1)` 等编号；“跳过”将源文件保留原位，已有目标保持不变；“替换”用源文件原子替换已确认的本地普通文件，源路径随归档移走。文件夹、链接及特殊文件不能替换。预览路径不包含最终编号。
5. 处理后可查看实际移动路径和问题详情；再次处理需要重新扫描。

“应用到本次归档的所有同名文件”只影响本次勾选项，不会处理未选文件，也不影响下载备份或下一次本地归档。目标在确认期间变化会重新询问；已选择批量替换时遇到不能替换的项目也会另行询问。等待时可以停止归档，返回工具首页后卡片提示“等待处理同名文件”，重新进入可继续选择。结果单独统计替换和跳过，并在实际移动路径中标记替换项。

如果选择的文件夹名称已经是四位年份（例如 `/视频/2022`），工具会自动识别为年份目录，只整理根目录散落文件：`2022/VID_20220801_120000.mp4` 直接移到 `2022/08月/`，已有月份目录及其内容保持不动，不会再创建 `2022/2022/`。该模式下“包含子文件夹”关闭且不可勾选。缺少的月份按需新建；同月有多个目录时仍需选择。识别日期不属于目录年份的文件保留原位并在预览中提示，不会把 2021 年的视频混进 2022 年的 12 月目录，也不会自动移到所选目录外。

例如，没有有效拍摄元数据时，`20130607_190722.jpg` 归入 `2013/06月/`，`20121209_015.jpg` 归入 `2012/12月/`；文件名没有明确日期时才用创建日期。文件名和创建日期都可能受导出或重命名影响，请核对预览。明确时区的拍摄字符串保留其记录的年月；无时区和创建日期按 Mac 本地时区归类。

扫描不移动文件或创建目录。执行保留文件内容、EXIF、创建日期和修改日期，不清理空目录；隐藏文件、链接、照片资料库、应用包及其他子挂载卷会跳过。扫描后文件或根目录变化时拒绝或跳过。仅在同一卷内移动；无冲突及保留两者优先独占移动；exFAT 等不支持的磁盘会优先采用系统文件协调与空占位核验，在同盘直接移动原文件，保留内容和日期，不再默认复制整份媒体。归档期间避免其他程序同时写入同一目标目录；不参与系统协调的程序仍存在检查与移动之间的竞争窗口。只有普通移动也不支持时，才创建副本、校验内容并按卷精度保留创建/修改日期，确认完整后移除源。兼容路径需要一个文件副本的额外空间及 64 MiB 预留，界面显示复制和校验进度，耗时比直接移动长。日期精度有限的磁盘可能按秒存储时间。正常失败或停止保留源文件并清理未完成副本，强退或拔盘可能残留空占位或副本，不会自动清理历史占位。替换仅在明确确认后执行。视频元数据能否读取取决于系统和文件格式，读取不到时按上述规则回退。

停止或退出只停止剩余文件，已归档文件保留在新目录，不自动恢复原路径或被替换的目标内容。归档不修改源文件日期；若需只修复日期并保留名称，请另用“图片/视频日期修复”。已在 wxx_4T 的 exFAT 卷上用独立合成文件验证直接移动和兼容归档；大量真实文件耗时及更多卷兼容性尚待实测。

## 按拍摄时间重命名

在“本地工具”首页点击“按拍摄时间重命名”，可读取已有图片和视频的原始时间，在原文件夹中统一命名，并同时同步文件创建日期和修改日期。

1. 选择文件夹；默认处理图片和视频并包含子目录，可按需取消类型或关闭子目录扫描。
2. 查看分页预览中的原路径、新路径和两种文件日期的变化。图片格式示例为 `IMG_20151101_145451.jpg`、`IMG_20151101_145451.png`，视频为 `VID_20250704_005959.mp4`。保留原扩展名及大小写，例如 `.JPG`、`.MOV`，不会转换文件格式。
3. 默认勾选需要处理的文件，可逐项选择、本页全选或全部选择/清空，跨页保留。已经符合名称及日期的文件标记无需处理；名称正确但日期不同的文件只同步日期。
4. 点击“重命名已选 N 个文件”并确认。所有文件留在原父目录，不创建归档目录。同名时可选择保留两者、跳过或替换；保留两者自动加 ` (1)` 等编号，下次扫描不会反复追加编号。其他待改名源文件不能被替换，避免处理顺序造成文件丢失。
5. 查看已重命名、已同步日期、跳过和失败数量，以及实际处理路径。若改名成功但日期写入失败，会明确提示；再次扫描可以继续核对或同步日期。

图片优先 EXIF 原始拍摄时间，其次内嵌创建时间；视频使用系统能读取的内嵌拍摄/创建时间。缺失或无效时，默认从文件名读取完整年月日时分秒，例如 `IMG_20130525_120612.jpg`、`20130607_190722.jpg`、`VID_20250704_005959.mp4`，预览标明“文件名日期”。只有年月日（如 `20121209_015.jpg`）、日期或时间无效、多个日期/时间冲突时跳过，不补为午夜；元数据和文件名都没有有效时间时跳过，不使用文件创建/修改日期或 TIFF 通用修改时间。文件名日期是推测，请核对预览；文件名已符合时仍可同步两种文件日期。命名保留元数据字符串记录的当地时间，文件日期尊重元数据时区；文件名补充或元数据没有时区时按扫描时的 Mac 当前时区解释，部分磁盘按秒保存日期。

工具不改变图片/视频内容或 EXIF，不重编码；隐藏文件、链接、资料库及应用包不处理。与本地归档共用同盘快速移动及同名保护，操作期间避免其他程序同时写入目标。停止只影响剩余工作，已完成的改名与日期修改保留，退出后需重新扫描。

## 文件预览

在目录栏选择“列表”或“预览”。选中一个文件后按空格、⌘Y、点击眼睛按钮或双击文件可打开预览，Esc 或“关闭”退出。搜索框中的空格仍用于输入。

| 类型 | 查看方式与限制 |
| --- | --- |
| 图片、PDF、RTF、Office / OpenDocument | 系统 Quick Look，显示效果取决于 macOS 和系统预览组件。 |
| 纯文本、Markdown、CSV/TSV、日志、JSON、XML、YAML | 只读文本视图，可选择复制；仅显示前 1 MiB，Markdown 按源文本查看。 |
| 视频与常见音频 | 原生播放器，提供播放、暂停和进度控制；视频支持全屏，编码兼容取决于 macOS。 |
| 未支持格式 | 显示下载后打开的提示，不为预览读取内容。 |

完整预览会先将整个文件读取到 Mac 私有临时目录，即使文本只显示前 1 MiB。大文件需要等待读取，当前不支持边传边播。关闭预览、换设备或正常退出时清理临时文件，不影响正式下载。

网格为视口内及上下少量邻近区域的图片和视频加载缩略图，优先使用手机提供的缩略图；不可用时，仅允许不超过 16 MiB 的小图片回退读取原图，不自动下载完整视频、文档或音频。离屏缓存被淘汰后可重新加载。

缩略图请求整体失败时，会在旧 helper 结束后自动重试一次；仍失败时显示原因和手动重试入口。单张缩略图不可用或无法解码时提供手动重试，完整 MTP 响应确认的单文件不可读只影响该项；USB 超时、断开或会话错误会停止当前请求。缩略图不可用时仍可主动请求完整预览。

## 语言与外观

“设置 → 通用”提供跟随系统、简体中文和英文；语言更改在下次启动生效，未知系统语言回退简体中文。手机文件名、存储描述和既有报告文件名保持原样。

外观支持跟随系统、浅色和深色，切换立即生效并保存，只改变渡舟的外观。翻译资源与新增语言步骤见[本地化文档](localization.md)。

## 排障与清理

| 现象 | 建议 |
| --- | --- |
| `LIBUSB_ERROR_NOT_FOUND` 或无法打开 MTP 会话 | 只保留一个渡舟实例，退出其他传输或照片导入程序，重新插拔数据线并选择“文件传输”；持续失败时记录具体错误阶段。 |
| `LIBUSB_ERROR_ACCESS` | 检查接口占用，必要时开启临时接管并完成管理员认证。无需关闭系统安全保护。 |
| 引擎退出码 9 / SIGKILL | 结合系统日志判断原因；ad-hoc helper 携带受限制的设备访问 entitlement 可能导致启动被拒绝，默认构建不携带该权限。使用默认脚本重新构建。 |
| 停止后仍在等待 | 取消会等待当前文件或设备操作结束，大文件可能需要较长时间。异常兜底退出后可能需重新插拔手机，详情见 USB 授权说明。 |
| 提交文件失败 | 检查目标盘可写状态、可用空间与连接；同名文件会询问处理方式，选择保留两者会自动编号。exFAT 最后保存阶段需额外本地复制，请等待完成。 |
| 目标位置权限拒绝 | 通过“更改…”重新选择可写文件夹，无需授予“完全磁盘访问”。 |
| 强制退出留下 `.part` | 退出应用并确认不再需要该未完成文件后，可手动删除任务中的 `.ferry-*.part`，已完成文件保留。 |

大于 4 GB 的真机文件、跨品牌和长期运行等场景尚无完整验证记录，详见[验证状态](validation.md)。

### 卸载

退出并删除 `Ferry.app`。应用不会安装后台服务。设置、上次保存位置与“经常访问”目录历史保存在 macOS 的 `local.ferry.app` 偏好域，任务恢复索引保存在 `~/Library/Application Support/Ferry/download-tasks.json`，报告与独立恢复清单保存在 `~/Library/Application Support/Ferry/Transfers`，删除应用不会自动清除这些数据；可在界面恢复默认隐藏和列表视图，并通过目录的右键菜单移除“经常访问”记录。下载内容及任务报告由用户保留。

开发缓存位于项目内 `.build/`、`.cache/`，构建产物位于 `dist/`，不需要时可删除。强制退出可能留下系统临时目录中的 `Ferry-media-*`，确认应用已退出后可删除。
