# 渡舟 Ferry

把 Android 文件只读拷到 Mac。也可以不连手机，整理 Mac 上已有的图片和视频。

手机端无需安装 App，也无需开启 USB 调试。界面支持简体中文与英文、浅色与深色，界面上的话是“让文件，轻松靠岸”。界面使用 SwiftUI，USB/MTP 在独立进程中运行。

> **当前为 0.0.1 本地预览版**，面向 macOS 14+。应用为本地签名，没有 Developer ID，也没有 Apple 公证。设备兼容性与测试范围见[验证状态](docs/validation.md)。

## 想做什么

| 想做的事 | 入口 |
| --- | --- |
| 把手机里的文件拷到 Mac | 连接后下载。要按拍摄年月分文件夹，先在“设置 → 下载”打开对应归档 |
| 只改硬盘上照片、视频的创建日期 | 本地工具 → 图片/视频日期修复 |
| 把已有文件挪进 `2022/01月/` | 本地工具 → 图片/视频归档 |
| 文件名改成 `IMG_` / `VID_`，并同步创建、修改日期 | 本地工具 → 按拍摄时间重命名 |
| 找出字节完全相同的图片 | 本地工具 → 重复图片整理，副本移入废纸篓 |

连接后可以浏览目录、搜索、按修改年月和图片/视频筛选，并从“经常访问”直达常用目录。默认不显示点号文件和文件夹。列表与缩略图可以预览图片、视频、常见文档和音频。下载保留目录结构；传输过程中可以继续追加任务，查看进度、用时和预计剩余时间。

本地工具以卡片列出用途和运行状态。返回首页不会打断正在运行的任务。扫描只预览，确认后才改日期、移动或改名。

手机端只读：

- 不上传、不删除、不重命名手机上的文件。
- 多台手机接入时选择其中一台，始终只有一个活动会话。
- 重复图片只把确认的副本移入系统废纸篓，不永久删除。

下载时的年月归档在“设置 → 下载”，默认关闭，只处理这次从手机导出的文件。图片优先 EXIF，视频优先内嵌或容器日期，再没有就用手机上的修改日期。本地“图片/视频归档”只移动文件夹里勾选的已有文件：拍摄元数据优先，其次文件名日期，再次创建日期，不用修改日期。说明见[按拍摄年月归档图片](docs/usage.md#按拍摄年月归档图片)、[按拍摄年月归档视频](docs/usage.md#按拍摄年月归档视频)和[本地图片/视频年月归档](docs/usage.md#本地图片视频年月归档)。

日期修复和按拍摄时间重命名都会先读拍摄元数据。没有元数据时，日期修复默认从文件名识别日期；仅有年月日时设为当天 00:00。可以关闭文件名补充，或关闭“仅恢复年月日”。日期修复默认只改创建日期，原文件名保留。重命名要求文件名中有完整的年月日时分秒，预览会标明“文件名日期”；只有年月日、时间无效或相互冲突时跳过，不补成午夜，也不用文件的创建或修改日期。见[图片/视频日期修复](docs/usage.md#本地图片日期修复)和[按拍摄时间重命名](docs/usage.md#按拍摄时间重命名)。

## 快速开始

推送与 `Resources/Info.plist` 一致的版本标签后，GitHub Actions 会在 Apple Silicon 的 macOS 运行器上测试并发布预览包。当前版本对应标签 `v0.0.1`。发布页附带 ZIP、libusb 完整源码包和 `SHA256SUMS`。包是本地签名，没有 Developer ID，也没有 Apple 公证。发布出现之前，按下面的步骤从源码构建。

### 1. 从源码构建

目前以源码构建为主要使用方式。需要 macOS 14+、Xcode / Swift 工具链、Go 1.26+、`pkg-config` 和 Python 3。构建环境说明见[验证状态](docs/validation.md)。

缺少工具时，可安装 Xcode Command Line Tools，并通过 Homebrew 安装 Go 和 pkg-config：

```sh
xcode-select --install
brew install go pkg-config
```

取得源码后，在仓库根目录运行：

```sh
./scripts/test.sh
./scripts/build-app.sh
open dist/Ferry.app
```

默认测试使用模拟设备；仅在显式设置真机测试环境变量时连接手机。首次构建会下载固定版本的 libusb 源码并核对 SHA-256，在项目内编译。Go 使用仓库内固定的 vendored 依赖，不需要安装系统级 libusb。

构建生成当前 Mac 架构的 `.app`、ZIP、libusb 源码包和校验文件。`dist/Ferry.app` 采用 ad-hoc 本地签名，没有 Developer ID，也没有 Apple 公证。macOS 可能拦截未公证应用。仓库没有另写放行步骤，请按系统提示处理。

### 2. 从手机下载

1. 用支持数据传输的 USB 线连接手机，解锁并选择“文件传输”，允许手机端的文件访问提示。
2. 退出 OpenMTP、Android File Transfer 等可能占用 MTP 的工具。单台手机会自动连接；多台接入时，在左侧“我的设备”选择一台后点击“手动连接”。
3. 双击进入目录，单击文件名或勾选项目；支持 ⌘ / Shift 多选，也可先按年月或类型筛选，再点“全选”。
4. 选择保存位置，点击“下载到 Mac”。默认直接保存到所选位置；同名文件会弹窗询问保留两者、跳过或替换。需要按批次归档时，勾选“为本次下载创建文件夹”。在左侧“下载任务”查看进度、报告或打开结果目录。

启用临时 USB 接管时，本地包可能弹出 macOS 管理员认证。连接建立后，helper 永久降回当前用户权限，再浏览和下载。不安装后台服务，不保存密码，也不终止系统相机服务。接管期间，所选手机的照片导入或 ADB 可能短暂不可用，断开后归还。说明见 [USB 授权](docs/usb-access.md)。

### 3. 只整理本机文件

侧栏打开“本地工具”，选择对应卡片。这些工具处理选定的 Mac 文件夹，不需要连接手机。

没有手机时，可以在“设置 → 体验与测试”开启“演示模式（示例数据）”，点击“连接演示手机”；也可以运行：

```sh
open dist/Ferry.app --args --demo
```

演示模式不访问手机。下载仍会向选定的 Mac 目录写入合成文件。

## 使用前须知

- **同名文件会询问。** 可选保留两者、跳过或替换。“全部应用”只对当前这次下载或这次本地归档生效。替换只作用于已经完整写入并校验过的本地普通文件。
- **未完成的任务要手动继续。** 取消会等当前文件或正在进行的设备操作结束，再停止剩余任务。退出前会确认。下次启动时，未完成任务显示“等待恢复”；连接原手机后点击“继续未完成”，不会自动传输。手机没有稳定标识时，只能在原来那次连接里继续。单个文件不支持从中断处接着传。
- **SHA-256 是本地落盘文件的摘要。** 它不表示已经和手机端的哈希比对过。
- **完整预览会先把整个文件读到 Mac 的私有临时目录。** 网格不会自动下载完整视频、文档或音频。能否播放取决于 macOS 解码器。

exFAT 的额外复制与临时空间、筛选规则、预览格式和清理方法见[使用指南](docs/usage.md)。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 会不会改手机上的文件 | 不会。浏览、预览和下载都只读取手机。不上传、不删除、不重命名。 |
| 为什么弹出管理员认证 | 临时接管被系统占用的 USB 接口时需要。连接建立后 helper 永久降回当前用户权限，不安装后台服务，不保存密码，也不终止系统相机服务。可在“设置 → USB 连接”关闭接管，仍可尝试普通连接。 |
| 下载归档和本地归档怎么选 | 下载归档只整理这次从手机导出的文件，在“设置 → 下载”里开关。本地归档整理已经在 Mac 上、且已勾选的文件。两边使用的日期来源不同，见上文“想做什么”。 |
| 第一次打不开应用 | 本地预览包没有 Developer ID，也没有公证，macOS 可能拦截。请按系统对未公证应用的提示处理，并查看[验证状态](docs/validation.md)里的签名说明。 |
| 找不到手机 | 检查数据线、解锁状态和 USB“文件传输”模式；退出其他 MTP 应用。多台接入时先选择目标手机。 |
| 提示接口被占用或 `LIBUSB_ERROR_ACCESS` | 退出其他传输或照片导入程序。需要时在“设置 → USB 连接”允许临时接管，并完成系统认证。 |
| 大目录读取慢或大小显示“未读取” | 首次枚举可能较慢。大小按需读取，可点击“读取大小”或按大小排序。手机内容变化后使用“刷新目录”。 |
| 下载失败后队列暂停 | 检查连接，连接原手机后点击“继续队列”。失败任务不会自动重跑，需要重新选择并加入队列。 |
| 无法预览某种格式 | 扩展名可识别，不代表系统支持其编码。可以下载后用其他应用打开。 |

连接错误、引擎退出与临时文件处理见[使用指南中的排障说明](docs/usage.md#排障与清理)。反馈问题时请附系统版本、手机型号、复现步骤和脱敏错误信息，避免公开文件名清单、传输报告或设备抓包。

## 隐私与权限

应用无账号、遥测或自动更新。运行时不上传文件、文件名或设备信息。源码构建与 CI 需要联网。请求通过本地进程通信传递，不监听网络端口。

应用未启用 App Sandbox。USB/MTP 由独立 helper 处理。临时接管使用一次性系统授权，不安装常驻提权服务，也不保存密码。

下载报告在本机的 `~/Library/Application Support/Ferry/Transfers/`，里面有文件名和设备显示名称。“经常访问”的目录路径与访问统计保存在本地应用偏好中。请按个人数据保管。

检查入口为 `./scripts/test.sh`，打包入口为 `./scripts/build-app.sh`。可用 Xcode 打开 `Package.swift`；日常运行建议使用打包后的 `.app`。请保留 `-mod=vendor`，重新执行 `go mod vendor` 会覆盖本地补丁。版本以 `Resources/Info.plist` 为准。

测试构建目录可通过 `FERRY_TEST_BUILD_DIR` 指定；打包支持 `FERRY_BUILD_DIR` 和 `FERRY_DIST_DIR`。调试可用 `FERRY_ENGINE_PATH` 指定 helper，`FERRY_DEMO=1` 强制使用演示设备。

推送到 `main` 和拉取请求时会运行验证与构建。`v*` 标签会另外发布预览包，标签必须与 `Resources/Info.plist` 的版本一致，例如 `v0.0.1`。发布运行器是 `macos-15`（Apple Silicon），产物为 ZIP、libusb 完整源码包和 `SHA256SUMS`。
